# 04 · 试玩反馈修复（节奏 / 赛车 / 拆弹）

> 实现者：Kimi · 基于真实试玩反馈的体验修复，只改你自己的 3 个模块文件
> 设计原则：**错因诊断**——错误可归因时给具体操作提示，不靠泛化错误音
>
> **状态说明（v1.2 同步）**：本节修复均已落地，但部分内容在后续试玩轮被更直接的方案取代，
> 各节以「终版」标注实际实现，与代码保持一致。验收以现行代码为准（见第 4 节更新）。

## 1. 节奏模式：新手太快的三处修复

### 1.1 判定窗口放宽
- 初版：Perfect ±120ms → ±150ms；Good ±250ms → ±300ms
- **终版（第二轮试玩「那条线时间剩余不多」后）**：Perfect **±150ms**；Good **提前 600ms ~ 延后 350ms**（不对称窗口，早敲更宽容）；漏击线同步为 +350ms。与 01 规格书第 4 节 v1.2 一致

### 1.2 降速方案
- 初版设想：默认 BPM ×0.8 +「原速」开关（`rhythm_speed`）
- **终版（未采用开关）**：直接改为六首歌 BPM 梯度 **55/75/85/90/95/100**，第一首《小星星》55 bpm 足够慢，无需额外开关；音符预览时间（顶部→判定线）加长到 2.4s。与 01 规格书第 3 节 v1.2 一致

### 1.3 首局引导
- **终版（未单独实现）**：选曲屏常驻提示语「🎵 键盘即琴键：音符落到黄线的一瞬，敲下对应的键！」已覆盖同等信息；判定线下方另有「下一个音符」巨型键帽提示（到线前 800ms 出现），无需首局一次性引导条

## 2. 打字赛车：空格提交提示 → 终版改为自动切词

- 初版按本节实现：词完成瞬间显示跳动胶囊「按空格提交」
- **终版（用户试玩后拍板）**：提示仍会被忽略，直接改交互——**单词打完自动切下一词**（停顿 250ms），空格键不再参与玩法，词中按空格也不罚。与 03 规格书第 3 节 v1.2 一致

## 3. 拆弹专家：大小写错因诊断

- **终版**：当前字符为大写时，句子下方常驻显示「⇧ 按住左/右 Shift 敲「X」」胶囊（左右侧按指法规则判断，带常态脉动）；敲错大小写（字母对、case 反）时胶囊变红加急闪烁；该小写却敲出大写时提示「松开 Shift」。与「3 秒淡出 + 每句节流 2 次」方案等效且更直观（光标停在大写字符上提示就一直在）
- 其余错误保持红闪 + 错误音，不加提示（避免干扰）

## 4. 验收标准（已与现行代码对齐）

节奏：
1. 选曲屏 6 张卡；第一首《小星星》55 bpm；音符下落预览约 2.4s
2. 提前 ~450ms 敲对键判 Good 而非 Miss；压线敲判 Perfect

赛车：
3. 单词打完不按任何键，250ms 后自动切下一词，里程 +33.3 米
4. 词中打错仍记一次错误（-16.7 米）；词中按空格不罚不切词

拆弹：
5. 光标落在大写字符时出现 Shift 提示胶囊
6. 敲小写代替大写时胶囊变红加急；敲完全无关字符不出现（只闪红）
7. 倒计时从 90 秒起步

全部：无 JS 报错；改动仅限自己的 3 组模块文件（后续轮次经用户授权另改了 index.html 菜单顺序与 battle.js 锁定逻辑，见 git 记录）。
