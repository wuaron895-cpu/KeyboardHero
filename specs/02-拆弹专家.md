# 02 · 拆弹专家（倒计时剪线）规格书

> 实现者：Kimi · 接口：`window.KeyForce.bomb = { start: start, abort: abort }` · 文件：`js/bomb.js` + `css/bomb.css`
> 前置必读：`00-协作约定.md`

## 1. 玩法概述

一颗炸弹倒计时 **90 秒**（v1.1 修正：原 60 秒对入门玩家必爆——3 句约 70 字符，10 WPM 需 80 多秒）。屏幕显示 3 句英文短句（随机取自 `D.SENTENCES`，不重复），**逐句敲对即剪断一根线**。3 句全对 = 拆除成功，按剩余时间与准确率计分。倒计时归零 = 爆炸，本局失败。

训练点：**短句 + 大写 Shift + 句号**（对应第 18 关内容）在压力下的实战。

## 2. 输入规则

- 目标句显示为大字串（空格显示 `␣`），当前字符光标下划线，已打对字符变绿、打错红闪（直接复用 `train-text` 的 `.ch .done .badflash` 视觉语言即可，DOM 自建）
- **必须打对才前进**（与闯关训练一致）；打错 = 记一次错误 + 短促警报音（复用 `KF.audio.error()` 或自建更尖锐的「滴」）
- 敲完一句（含句号）→ 剪线动画（该句对应的一根线断开下落，音效自建「咔嚓」）→ 立刻显示下一句
- 大写在判定时按 `ev.key` 直接比较（无需额外处理，浏览器已给大写字符；提示玩家用另一侧 Shift，与训练页规则一致）
- **大写随行提示（v1.1 新增）**：当前字符为大写时，句子下方自动显示「⇧ 按住左/右 Shift 敲「X」」胶囊（左右侧按指法规则判断）；字母对但大小写敲反时，胶囊变红加急闪烁（该小写却敲出大写则提示「松开 Shift」）。试玩反馈：无提示时玩家不知道为何卡住
- 计时从第一句显示开始；开局有 1.5s「准备」横幅（无计时）

## 3. 计分与杯数

- 得分 = 剩余秒数 × 10 + 正确字符数 × 5（拆弹成功时）
- 杯数：**成功 +20 🏆**；刷新历史最高分（存档 `bomb_best`，存分数）额外 **+10 🏆**
- 失败：0 杯，鼓励语「差一点！再来一次」
- 中途退出（abort）不给杯

## 4. 界面结构（单屏 `#screen-bomb`，动态构建）

- `header.bar`：返回（确认后 `KF.refreshMenu()`）+ 标题「拆弹专家」
- 主体中央炸弹区：💣 emoji 大图（CSS 呼吸/摇晃动画），顶部倒计时条（>20s 绿色、>10s 黄色、≤10s 红色 + 心跳加速动画与滴答音加速——滴答用 setTimeout 链，音量小）
- 炸弹下方：3 根线（3 个横置色条，红/蓝/黄），未剪的完整、已剪的断开垂落
- 目标句面板：奶油贴纸面板，居中大字
- 实时数据：剩余时间、错误数、准确率
- 爆炸动画：全屏红色闪光 + 震屏（复用 `.shake` 思路）+ `KF.audio.boom()`（可直接调用）；成功动画：金色闪光 + 成功横幅
- 结算浮层：得分 / 准确率 / 杯数 / 「再来一局」「返回」按钮（按钮样式 .btn / .btn-primary）

## 5. 关键实现约束

- 倒计时与渲染用 rAF（步长钳制 0.05s，参考 battle.js）；结束时清理全部 rAF/定时器/滴答链
- keydown 只在该屏 active 时生效；忽略组合键；`ev.preventDefault()` 仅对字母/空格/句号等有效输入
- 中文输入法提示：`ev.isComposing || ev.key === 'Process'` 时显示一次性提示条（「⚠ 输入法未关闭！按 Shift 切到英文」）

## 6. 验收标准

1. `KF.bomb.start()` 进入游戏屏，出现 3 根线与第一句，无 JS 报错
2. 敲对第一句全部字符：该线断开动画触发，自动切到第二句
3. 故意敲错：错误数 +1，光标不前进
4. 三句全对：成功结算，`store.get('bomb_best')` 更新，杯数 +20（或含纪录 +10）
5. 失败路径：可手动把倒计时调快验证（或集成方注入）——爆炸动画 + 0 杯
6. 「再来一局」完全重置（时间/句子/线/计数）
7. 全程无 JS 报错
