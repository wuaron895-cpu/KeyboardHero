## 3. 模块接口协议

每个模块文件是 IIFE，结尾必须挂全局接口（命名见各规格书）：

```js
window.KeyForce.rhythm = { start: start, abort: abort };
```

- `start()`：打开模块（无参或按规格书签名）；`abort()`：中途退出回到模块自身入口，无需切换全局屏幕
- 所有 DOM 由模块运行时动态创建：向 `document.body` 注入 `<section id="screen-xxx" class="screen">`（保持现有屏幕体系），再用 `KF.show('screen-xxx')` 切换；退出调用 `KF.refreshMenu()` 回主菜单
- 屏幕 DOM 结构参考现有约定：顶部 `<header class="bar">`（返回按钮 `btn btn-back` + 标题 `<h2>`）

## 4. 可复用的全局 API（直接调用，不要重新实现）

```js
var KF = window.KeyForce, D = window.KeyForceData;

KF.show('screen-xxx')        // 屏幕切换（.screen 加 .active）
KF.refreshMenu()             // 回主菜单（含段位刷新）
KF.addCups(n)                // 加杯数（成长货币，自动持久化）
KF.store.get(key, def)       // 读存档（内部自动加 keyforce_ 前缀）
KF.store.set(key, val)       // 写存档（JSON 序列化）
KF.audio.note(freq)          // 琴声（三角波+泛音，音符模式同款）
KF.audio.correct()/error()   // 击键正确/错误音
```

数据（`D.`）：`D.SENTENCES`（10 句短句，含大写+句号）、`D.WORDS`（90 高频词）、`D.SONG_SCALE`（简谱→频率）、`D.NOTES`（键→{freq, jp}）、`D.TIERS`（段位表）。

存档 key 建议：`rhythm_best`（各曲最高评级）、`bomb_best`、`race_best` 等。

## 5. 音效约定

模块内自建 WebAudio（IIFE 闭包内，参考 `app.js` 的 `tone()`/`noise()` 写法即可），或复用 `KF.audio.*`。约束：

- 音量 ≤ 0.2（与现有音效一致，防爆音）
- 静音开关：播放前检查 `KF.store.get('muted', false)`
- 音频上下文需在首次用户交互后创建（浏览器自动播放策略），参考 app.js 的懒创建

## 6. 视觉风格约定（拉布布潮玩风）

直接引用现有 CSS 变量（style.css 已定义）：`var(--ink)` 深描边色、`var(--cream)` 奶油面板底、`var(--yellow)` 高亮黄、`var(--orange)` 强调橙、`var(--red)`/`var(--green)` 判定色、`var(--dim)` 次级文字、`var(--sky2)` 数字蓝、`var(--mono)` 等宽字体（标签/字母用）。

统一语言：**3px 深描边 + 硬阴影 `box-shadow:0 4px 0 rgba(43,58,74,.3)` + 圆角 14-18px**；面板奶油底；字体粗重、字母间距大。背景沿用 body 已有的暮紫灰→雾蓝渐变（模块容器透明即可）。

## 7. 键盘监听约定

- 全局 `keydown` 监听必须同时检查：`$('screen-xxx').classList.contains('active')` + 模块自身运行标志 + 无升级/结算浮层遮挡，防止训练页/保卫战页串键
- 忽略 `ctrlKey/metaKey/altKey` 组合键；只响应自己需要的键
- `ev.preventDefault()` 拦截的键要与现有两模块不冲突（训练用字母、战斗用字母+数字 1-4+Esc；**拆弹/赛车模块的键尽量避开数字 1-4 和 Esc**，或自行检查屏幕 active 即可，无冲突）
