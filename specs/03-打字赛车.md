# 03 · 打字赛车（竞速模式）规格书

> 实现者：Kimi · 接口：`window.KeyForce.race = { start: start, abort: abort }` · 文件：`js/race.js` + `css/race.css`
> 前置必读：`00-协作约定.md`

## 1. 玩法概述

1000 米赛道，玩家赛车与一辆**幽灵车**（半透明，代表历史最佳 WPM）同场竞速。屏幕上方滚动显示目标单词，**打对 = 加速前进，打错 = 减速后退**。先冲线者胜。

训练点：**单词连打的节奏与 WPM 冲刺**（对应第 17 关高频词）。

## 2. 进度模型（写死，不要改）

- 每局 30 个单词（随机取自 `D.WORDS`，同局不重复）
- 玩家里程 = `max(0, 已打对词数 − 打错词数 × 0.5) / 30 × 1000 米`
  - 打对一词 +33.3 米；打错一词倒扣 16.7 米（下限 0）
- 幽灵车里程 = `已用秒数 × ghostSpeed`，其中 `ghostSpeed = max(2.0, 历史最佳WPM × 0.7) 米/秒`，历史最佳 WPM 来自 `store.get('stats').bestWpm`（无记录时幽灵车不出现，改为「暂无纪录」提示）
- **配速公式说明（v1.1 修正）**：30 词 ≈ 24 标准词当量，按 WPM 定义完赛时间 = 1440/WPM 秒，故幽灵速度 = 1000×WPM/1440 ≈ 0.7×WPM m/s——幽灵车即「按历史最佳 WPM 完赛的自己」，赢它 = 刷新纪录。原 v1 的 ×6 会让幽灵车 8-10 秒冲线、玩家必败
- 冲线判定：玩家里程 ≥ 1000 即完成；幽灵车先到则本局「落败」（仍结算，见下）

## 3. 输入规则

- 当前词显示在赛道上方横幅（大字 + 当前字符高亮），已打对字符变绿、打错红闪（视觉语言同训练页）
- **单词打完自动切词（v1.2 修正）**：最后一字母敲对即计进里程 + 车加速冲刺动画 + 轻快音，停顿 250ms 自动切换下一词；空格键不再参与玩法。原 v1 为「空格提交」，试玩发现无提示时玩家不知道要按空格、卡在当前词
- 打错词内字符 → 错误音 + 车尾刹车红光，一个词只记一次错误（倒扣 16.7 米）
- 单词全部小写，输入比较用 `ev.key.toLowerCase()`；仅字母生效（空格仅 preventDefault 防页面滚动）
- keydown 只在该屏 active 时生效；忽略组合键

## 4. 计分与杯数

- 用时 = 开局到冲线秒数；结算 WPM = 正确字符数 / 5 / 用时分钟（真实打字速度，与训练页口径一致）
- 杯数：**完成（玩家先冲线）+15 🏆**；刷新历史最快用时（存档 `race_best`，存秒数）额外 **+10 🏆**；落败（幽灵先到）0 杯
- 中途退出（abort）不给杯

## 5. 界面结构（单屏 `#screen-race`，动态构建）

- `header.bar`：返回（确认后 `KF.refreshMenu()`）+ 标题「打字赛车」+ 实时 WPM
- 赛道区：横向赛道（CSS 渐变路面 + 虚线车道），左侧起点、右侧 1000m 终点旗 🏁；玩家车 🏎️ 与幽灵车 👻🏎️ 按里程百分比定位（`left: x%`），带轻微上下浮动动画；领先/落后实时显示（「领先 12 米」/「落后 8 米」）
- 目标词横幅：赛道上方，当前字符下光标
- 里程表：`当前米数 / 1000m`
- 结算浮层：用时 / WPM / 胜负 / 杯数 / 「再来一局」「返回」
- 完成冲线时彩带 emoji 飘落（🎉 若干，CSS 动画）

## 6. 关键实现约束

- rAF 驱动（步长钳制），结束时清理全部 rAF/定时器
- 里程更新放在 rAF 每帧（幽灵车连续移动）；玩家车里程在打对/打错瞬间跳变 + 0.3s 缓动动画（CSS transition 即可）
- 30 词用完前无法冲线（里程上限 1000 由公式保证：30 词全对 = 1000 米）；幽灵车可能在玩家完成前冲线 → 立即结算「落败」

## 7. 验收标准

1. `KF.race.start()` 进入赛道屏，出现玩家车、目标词横幅，无 JS 报错
2. 打对第一个词：里程 = 33.3 米（或 DOM 位置对应），词切换
3. 打错：里程回退 16.7 米（下限 0）
4. 连打 30 词全对：完成结算，`store.get('race_best')` 更新，杯数 +15（或含纪录 +10）
5. 幽灵车存在性：`store.get('stats').bestWpm > 0` 时幽灵车元素存在且随时间前移
6. 「再来一局」完全重置
7. 全程无 JS 报错
